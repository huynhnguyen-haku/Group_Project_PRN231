# Milk Shop Backend System

## Introduction
The **Milk Shop Backend System** is an application that helps manage the operations of a milk shop, including purchases, reward points, online payments, and gift redemption. The backend provides APIs for communication with the frontend and database management.

## Technologies Used
- **Language**: C#
- **Framework**: ASP.NET
- **Database**: Microsoft SQL Server
- **Authentication and Security**: JWT

## Features
- **Customer Management**: Track customer information and reward points.
- **Reward Points System**: Update reward points based on purchase transactions.
- **VNPay Integration**: Allow customers to make online payments through VNPay.
- **Gift Redemption**: Enable customers to use reward points to redeem gifts.
- **Product Management**: Add, edit, and delete products.
- **Sales Transactions**: Process orders for purchasing products.
